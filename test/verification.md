# 検証記録

## 1. 概要

各文書の記述の根拠をまとめる。仕様と手順の文書には結論だけを書き、件数はこの文書に分けている。

## 2. 方法

### 2.1 PMM

1. 仕様のとおりに先頭から読む解析器を作り、ファイルの最後の byte まで過不足なく読めるかを確かめた。
2. すべてのキーフレーム列で、連鎖（PMM 2.3）が成り立つかを確かめた。
3. 値の分布を集計し、各項目の意味と矛盾しないかを確かめた。

### 2.2 EMM

1. すべての行を行の種類（見出し、値、空行、注釈）に分けて集計した。
2. 同じフォルダに同じ名前の PMM がある組について、`[Object]` の番号とパスを PMM のモデルとアクセサリに照らし合わせた。

### 2.3 PMX

PMM が参照する PMX のうち、手元にあり、ボーン名の一覧が PMM と一致したものについて、ボーン、モーフ、IK、外部親にできるボーン、表示枠の数を比べた。

### 3.4 PMM と PMX

| 項目 | 結果 |
| --- | --- |
| 対象 | PMX が手元にあった 115 モデル |

| モーフ名の一覧 | 105 モデルで完全に一致。9 モデルは数が同じで名前の一部が違う（調べた例はすべて、19 byte で切れたか、CP932 で表せない文字が失われたもの）。1 モデルは数が違う |
| IK ボーンの一覧 | 115 モデルすべてで、IK のビットを持つボーンと一致 |
| 外部親にできるボーンの一覧 | ボーン名が完全に一致した 110 モデルすべてで、PMX 4 章の条件と一致 |
| 表示枠の数 | PMX が手元にあった 1,162 モデルのうち、1,085 モデルで PMX の表示枠の数 + 1（すべてモーフあり）。77 モデルで PMX の表示枠の数と同じ（64 モデルはモーフなし、13 モデルはモーフあり） |

ボーン名とモーフ名の長さは 1,613 モデルのすべてで 19 byte 以下だった。

## 6. MMD 9.32 での実機検証

モデルのパスを `UserFile` を含まない相対パス（ファイル名だけ）に書き換えた PMM を作り、PMM とモデルを同じフォルダ（MMD のフォルダの外）に置いて開いた。

| 開き方 | 結果 |
| --- | --- |
| exe に PMM を渡して起動する（作業フォルダは実行フォルダ） | 「モデルファイルが見つかりません」の画面が出る。カレントフォルダが実行フォルダなので、相対パスが見つからない（動作 2.3、3.1） |
| 起動済みの MMD で、メニューの「開く」から開く | モデルが見つかり、読み込みが進む（カレントフォルダが PMM のフォルダになる。動作 3.1）。この PMM と PMX は一覧が食い違っていたため、続いて「モデル構造が違う」の画面が出た（関係 3.2） |
| 起動直後の MMD で、ウィンドウへドロップする（エクスプローラー以外の別のウィンドウからファイルをドラッグして重ねた） | 「モデルファイルが見つかりません」の画面が出る。ほかの操作をしていないので、カレントフォルダは実行フォルダのまま（動作 3.1） |
| モデルをメニューから読み込んだ後、ウィンドウへドロップする | モデルが見つかり、読み込みが進む。カレントフォルダが直前に読み込んだモデルのフォルダのまま残っている（動作 3.1） |

日本語の Windows（932）で、フォルダ名に簡体字中国語の文字（932 にない文字）を含む場所に PMM を置き、開き方を比べた。モデルのパスは絶対パスである。

| 開き方 | 結果 |
| --- | --- |
| exe に PMM のパスを渡して起動する | 「ファイルが読み込めません:22」の画面が出て、開けない（動作 3.1） |
| 起動済みの MMD で、メニューの「開く」から開く | 開ける。モデルが見つかり、読み込みが進む（動作 3.1） |

## 7. 壊れた PMM の実機検証

モデルが 1 体で表示枠が 17 の PMM（PMX の表示枠は 16、モーフあり）を基準にし、値を 1 つだけ書き換えた PMM を MMD 9.32 のメニューの「開く」から開いた。基準の PMM は、確認の画面が出ずに開けた。

| 書き換えた値 | 結果 |
| --- | --- |
| ファイルの末尾に 10 byte の 0 を足した | 読み込める |
| ヘッダの選択モデルを、実在しないモデル ID（77）にした | 読み込める |
| 選択中のボーンの添字を 99999 にした | 読み込める |
| IK ボーンの添字を 99999 にした | 読み込める |
| 外部親にできるボーンの添字を 99999 にした | 読み込める |
| カメラの最初のキーの親モデルを 77 にした | 読み込める |
| 外部親の現在状態の親モデルを 77 にした | MMD が落ちる |
| 外部親の現在状態の親ボーンの添字を 99999 にした（親モデルは実在） | MMD が落ちる |
| カメラの追従先のモデルを 77 にした | MMD が落ちる |
| 表示枠の数（項目 5）を 16 にした | 読み込める |
| 表示枠の数（項目 5）を 18、8、1、0、99 のどれかにした | MMD が落ちる |
