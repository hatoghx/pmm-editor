# 目次

MikuMikuDance のプロジェクトファイル（PMM）と、MikuMikuEffect の割り当てファイル（EMM）についての資料です。ファイルの形式、ファイル同士の関係、MikuMikuDance の動作、作業の手順をまとめています。

## 1. 文書の一覧

| 番号 | 文書 | 内容 | 読む場面 |
| --- | --- | --- | --- |
| 01 | [基礎知識](01-basics.md) | 用語、ファイルの種類、文字コード | 最初に読む |
| 02 | [PMM ファイル形式](02-pmm-format.md) | PMM のバイト構造 | PMM を読み書きするとき |
| 03 | [EMM ファイル形式](03-emm-format.md) | EMM のテキスト構造 | EMM を読み書きするとき |
| 04 | [VMD ファイル形式](04-vmd-format.md) | モーションファイルの構造 | モーションを取り出す、取り込むとき |
| 05 | [PMX の参照部分](05-pmx-reference.md) | PMM の一覧を PMX から作る方法 | モデルを PMM に入れるとき |
| 06 | [ファイル同士の関係](06-relations.md) | PMM と EMM、PMX、VMD の対応 | 複数のファイルをまたぐ作業のとき |
| 07 | [MMD の動作](07-mmd-behavior.md) | パスの探し方、PMM の開き方の違い | MMD でどう開かれるかを答えるとき |
| 08 | [作業の手順](08-operations.md) | 複製、削除、外部親、モーション、修復、収集、再リンク、新規作成 | ファイルを書き換えるとき |
| 09 | [質問と手順の対応](09-question-guide.md) | 依頼の例から手順を選ぶ表 | 依頼を受けたとき |
| 10 | [検証記録](10-verification.md) | 根拠、観測した値、未確定の事項 | 記述の確かさを確かめるとき |

## 2. 依頼を受けたときの進め方

1. [質問と手順の対応](09-question-guide.md) で、依頼に合う手順を探す。
2. 手順が指す [作業の手順](08-operations.md) の節を読む。
3. 手順の中で参照される形式の節（02 から 05）を読む。
4. 依頼が MikuMikuDance での見え方や開き方に関わるときは、[MMD の動作](07-mmd-behavior.md) を読む。
5. 記述に「未確定」とあるときは、[検証記録](10-verification.md) の 5 章で状況を確かめ、利用者にそのことを伝える。

## 3. 節番号の書き方

各文書はほかの文書の節を次の略称で指します。

| 略称 | 文書 |
| --- | --- |
| 基礎 | 01 基礎知識 |
| PMM | 02 PMM ファイル形式 |
| EMM | 03 EMM ファイル形式 |
| VMD | 04 VMD ファイル形式 |
| PMX | 05 PMX の参照部分 |
| 関係 | 06 ファイル同士の関係 |
| 動作 | 07 MMD の動作 |
| 作業 | 08 作業の手順 |

例えば「PMM 5.2」は PMM ファイル形式の 5.2 節です。
