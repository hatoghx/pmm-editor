# PMX の参照部分

## 1. 概要

PMM はモデルのボーン名、モーフ名、IK の一覧、外部親にできるボーンの一覧を、PMX ファイルから写して持っています。本書ではその一覧を PMX から作るために必要な部分だけを記録します。PMX 全体の形式は扱いません。

## 2. PMX から読む項目

| PMX の項目 | 使う情報 |
| --- | --- |
| モデル名、モデル名（英） | PMM のモデル名 |
| ボーン | 名前、フラグ（3 章） |
| モーフ | 名前 |
| 表示枠 | 数 |

PMX の文字列は UTF-16 か UTF-8 です（ヘッダで決まる）。PMM に写すときは ANSI コードページに直します。

## 3. ボーンのフラグ

PMX のボーンは 2 バイトのフラグを持ちます。PMM の一覧作りで使うのは次のビットです。

| ビット | 値 | 意味 |
| --- | --- | --- |
| 2 | 0x0004 | 移動できる |
| 3 | 0x0008 | 表示する |
| 4 | 0x0010 | 操作できる |
| 5 | 0x0020 | IK |

## 4. PMM の一覧の作り方

| PMM の項目（PMM 5.1） | PMX からの作り方 |
| --- | --- |
| ボーン名（項目 7） | PMX のボーンを、ファイルの順にすべて |
| モーフ名（項目 9） | PMX のモーフを、ファイルの順にすべて |
| IK ボーンの添字（項目 11） | IK のビット（0x0020）を持つボーンの添字を、昇順に |
| 外部親にできるボーンの添字（項目 13） | 先頭に −1。続けて、次のどちらかに当たるボーンの添字を昇順に |
| 表示枠の数（項目 5 と 18） | PMX の表示枠の数に 1 を足した値（PMM 5.8） |

外部親にできるボーンの条件は次のとおりです。

1. IK のビット（0x0020）を持つ
2. 移動できる（0x0004）、表示する（0x0008）、操作できる（0x0010）の 3 つのビットをすべて持つ

名前は ANSI コードページに直して 19 バイトで切ります（PMM 2.2）。
