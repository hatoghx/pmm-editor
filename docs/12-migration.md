# 移行

## 1. 概要

プロジェクトを別のフォルダや別のドライブ、別のパソコンへ移し、移した先で開けるようにする作業の手順です。利用者のパソコンで動く AI エージェント（デスクトップ版の Claude Code、Codex など）が、「このフォルダのこのプロジェクトを、あのフォルダへ移して」という指示を、ローカルで実行するときの手順として書いています。ファイルの集め方と配置は [パッケージ化](11-dependencies.md)、パスの検査は [安全性検証](10-validation.md) にあります。

## 2. 移行の種類

| 種類 | 内容 | 元のファイル |
| --- | --- | --- |
| 複製 | 移した先に写し、元は残す | 残す |
| 移動 | 移した先に写し、確認が済んだ後で元を消す | 最後に消す |
| 別のパソコンへ | 移した先の MMD の実行フォルダが、元と違う | 利用者の指定による |

## 3. 利用者に確かめること

| 内容 | 例 |
| --- | --- |
| 移すもの | 元のフォルダと、その中の PMM（複数あるときは、どれか） |
| 移し先 | 移し先のフォルダ。存在するか、空か |
| 種類 | 複製か移動か |
| 移し先の MMD の実行フォルダ | 別のパソコンへ移すとき |
| 同名のファイルがあるとき | 上書きする、番号を付ける、中止する |
| 移す範囲 | プロジェクトのフォルダだけか、MMD の `UserFile` にある共有の素材も含めるか |

確かめられないものは推測で決めず、利用者に尋ねます。

## 4. 手順

1. 元のプロジェクトを調べる。PMM と同じ名前の EMM、PMM が使うファイル、それらの依存ファイルを[パッケージ化](11-dependencies.md) の 4 章の手順で一覧にする。
2. 移し先を検査する。フォルダに書き込めること、パスの長さ（255 byte 以下）、ファイル名に使えない文字、PMM の文字コードで表せることを確かめる（[安全性検証](10-validation.md) の 4 章、5 章）。
3. 計画を示す。どのファイルをどこへ写すか、どのパスを書き換えるかの一覧を作り、利用者に示して同意を得る。同名のファイルがあるときは、3 章の指定に従う。
4. 写す。元のファイルは変えない。依存ファイルは元との相対位置を保って写す（[パッケージ化](11-dependencies.md) の 5.1）。
5. パスを書き換える。5 章の手順で、写した PMM と EMM を書き換える。
6. 確かめる。写した PMM と EMM を最後まで読み直し、すべてのパスが実在することを確かめる（[安全性検証](10-validation.md) の 3 章、5 章）。写したファイルの数と大きさを元と照らし合わせる。
7. 移動のときだけ、6 までに問題がなければ、元を消してよいかを利用者に確かめ、同意を得てから消す。消すときは、ごみ箱に入れる方法を優先する。

## 5. パスの書き換え

フォルダごと別の場所へ移したプロジェクトの、PMM と EMM の中の絶対パスを新しい場所へ書き換えます。壊れたパスを探して直す作業ではありません。

1. 移す前の共通のフォルダ（置換元）を決める。PMM の場所と、PMM と EMM のすべての絶対パスに共通する最も深いフォルダとする。
2. 移した後のフォルダ（置換先）を決める。
3. EMM の `UserFile` で始まる相対パス（EMM 5.2）を次の順で絶対パスに直す。
   1. 置換元の下にある `UserFile` フォルダで見つかれば、その絶対パスにして書き換えの対象にする。
   2. MMD の実行フォルダの `UserFile` だけで見つかれば、共有の素材とみなして書き換えない。
   3. どちらにもなければ、作業を中止して一覧を示す。
4. すべての絶対パスについて、置換元で始まる部分を置換先に置き換える。置換元で始まらないパスが一つでもあれば、何も変えずに中止して一覧を示す。
5. 新しい PMM と、同じ名前の EMM を書き出す。

## 6. 別のパソコンへ移すとき

- PMM のパスに `UserFile` が含まれるときは、移した先の MMD の実行フォルダの `UserFile` の下が先に探されます（[MMD の動作](08-mmd-behavior.md) の 2.2）。
- EMM と EMD の相対パスは移した先の MMD の実行フォルダを基準に探されます（[EMM ファイル形式](04-emm-format.md) の 5.2）。
- 共有トゥーンは移した先の MMD の実行フォルダの `Data` にあるものが使われるので、集めません（[MMD の動作](08-mmd-behavior.md) の 2.4）。
- 移した先の MMD にない素材は集めて写します。

## 7. エージェントが守ること

- 原本を変えない。書き換えは写した先のファイルにだけ行う。
- 消す、上書きするといった、元に戻せない操作は実行する前に利用者に確かめる。
- 結果（写したファイルの数、書き換えたパスの数、見つからなかったもの）を利用者に知らせる。
- 途中で失敗したときは、写した先を片づけるか残すかを利用者に尋ねる。元のファイルには手を付けていないので、そのままにする。
