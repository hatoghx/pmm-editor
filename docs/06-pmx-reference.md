# PMX の参照部分

## 1. 概要

PMM はモデルのボーン名、モーフ名、IK の一覧、外部親にできるボーンの一覧を PMX ファイルから写して持っています。本書ではその一覧を PMX から作るために必要な部分だけを記録します。PMX 全体の形式は扱いません。 また、パッケージ化のために、材質が参照するテクスチャを読む部分を 5 章に記録します。

## 2. PMX から読む項目

| PMX の項目 | 使う情報 |
| --- | --- |
| モデル名、モデル名（英） | PMM のモデル名 |
| ボーン | 名前、フラグ（3 章） |
| モーフ | 名前 |
| 表示枠 | 数 |

PMX の文字列は UTF-16 か UTF-8 です（ヘッダで決まる）。PMM に写すときは ANSI コードページに直します。

## 3. ボーンのフラグ

PMX のボーンは 2 byte のフラグを持ちます。PMM の一覧作りで使うのは次のビットです。

| ビット | 値 | 意味 |
| --- | --- | --- |
| 2 | 0x0004 | 移動できる |
| 3 | 0x0008 | 表示する |
| 4 | 0x0010 | 操作できる |
| 5 | 0x0020 | IK |

## 4. PMM の一覧の作り方

| PMM の項目（PMM 5.1） | PMX からの作り方 |
| --- | --- |
| ボーン名（項目 7） | PMX のボーンをファイルの順にすべて |
| モーフ名（項目 9） | PMX のモーフをファイルの順にすべて |
| IK ボーンの添字（項目 11） | IK のビット（0x0020）を持つボーンの添字を、昇順に |
| 外部親にできるボーンの添字（項目 13） | 先頭に −1。続けて、次のどちらかに当たるボーンの添字を昇順に |
| 表示枠の数（項目 5 と 18） | PMX の表示枠の数に 1 を足した値（PMM 5.8） |

外部親にできるボーンの条件は次のとおりです。

1. IK のビット（0x0020）を持つ
2. 移動できる（0x0004）、表示する（0x0008）、操作できる（0x0010）の 3 つのビットをすべて持つ

名前は ANSI コードページに直して 19 byte で切ります（PMM 2.2）。

## 5. 材質が参照するファイルの読み方

PMX のバージョンは 2.0 と 2.1 があり、ここで使う部分の配置は同じです。先頭から次の順に読みます。

| 順 | 項目 | 内容 |
| --- | --- | --- |
| 1 | 識別 | `PMX `（4 byte）、バージョン（f32） |
| 2 | 共通設定 | 個数（u8。通常 8）と、その個数の u8。先頭から順に、文字コード（0 が UTF-16 のリトルエンディアン、1 が UTF-8）、追加 UV の数、頂点の添字の大きさ、テクスチャの添字の大きさ、材質の添字の大きさ、ボーンの添字の大きさ、モーフの添字の大きさ、剛体の添字の大きさ |
| 3 | モデル情報 | 文字列 4 つ（モデル名、英名、コメント、英語のコメント） |
| 4 | 頂点 | 件数（i32）と、頂点ごとの記録。大きさは下に示す |
| 5 | 面 | 添字の件数（i32）と、頂点の添字の大きさ × 件数 |
| 6 | テクスチャ表 | 件数（i32）と、文字列 × 件数。パスは pmx のあるフォルダが基準 |
| 7 | 材質 | 件数（i32）と、材質ごとの記録（下表） |

文字列は長さ（i32）と、その長さの byte で書かれています。

頂点ごとの記録の大きさは次の合計です。

- 位置、法線、UV：12 + 12 + 8 byte
- 追加 UV：16 byte × 追加 UV の数
- ウェイトの方式（u8）と、方式ごとの内容（ボーンの添字の大きさを n とする）
  - 0：n
  - 1：2n + 4
  - 2：4n + 16
  - 3：2n + 4 + 36
  - 4：4n + 16
- エッジの倍率：4 byte

材質ごとの記録のうち、参照を読むのに必要な部分は次のとおりです。

| 順 | 項目 | 型 |
| --- | --- | --- |
| 1 | 材質名、英名 | 文字列 × 2 |
| 2 | 拡散色、鏡面色、鏡面の強さ、環境色 | 16 + 12 + 4 + 12 byte |
| 3 | 描画の標志 | u8 |
| 4 | エッジの色、エッジの太さ | 16 + 4 byte |
| 5 | テクスチャの添字 | テクスチャの添字の大きさ（符号付き。−1 は指定なし） |
| 6 | スフィアの添字 | 同上 |
| 7 | スフィアのモード | u8 |
| 8 | 共有トゥーンの標志 | u8 |
| 9 | トゥーンの添字 | 標志が 0 なら、テクスチャの添字の大きさ。標志が 1 なら u8 |
| 10 | メモ | 文字列 |
| 11 | 面の数 | i32 |

共有トゥーンの標志が 1 のとき、トゥーンの添字 0 から 9 は MMD が用意する `toon01.bmp` から `toon10.bmp` を指します。これらは MMD の実行フォルダの `Data` にあります。集める対象にはしません。
