# EMM ファイル形式

## 1. 概要

EMM は MME のエフェクト割り当てを保存するテキストファイルです。どのモデルやアクセサリに、どのエフェクトファイルを割り当てたかを記録します。

言葉の意味は [基礎知識](02-basics.md) にあります。PMM との対応と番号の決まりは [ファイル同士の関係](07-relations.md)、根拠は [検証記録](../test/verification.md) にあります。

## 2. 書式の基本

### 2.1 文字と改行

| 項目 | 内容 |
| --- | --- |
| 文字コード | 保存した環境の ANSI コードページ（基礎 7 章の表） |
| BOM | 付けない。UTF-8 の BOM があると MME は読み込みを中止する |
| 改行 | CR LF |
| 1 行の長さ | 1,023 byte まで |

### 2.2 行の種類

| 種類 | 形 | 内容 |
| --- | --- | --- |
| 見出し | `[名前]` | セクションの始まり |
| 値 | `キー = 値` | `=` の前後の空白は任意 |
| 空行 | | セクションの区切り |
| 注釈 | `;` または `#` から行末まで | 読み込みで無視される |

| 場合 | MME の扱い |
| --- | --- |
| 行頭と行末の空白 | 無視する |
| 同じセクションに同じキーが 2 回ある | 最初の行を使う |
| 値が空の行 | 読み込みを拒否する |

## 3. 全体の並び

| 順 | セクション | 必須 | 内容 |
| --- | --- | --- | --- |
| 1 | `[Info]` | 必須 | 形式のバージョン |
| 2 | `[Object]` | 必須 | 割り当ての対象になるモデルとアクセサリの一覧 |
| 3 | `[Effect]` | 必須 | メイン画面の割り当て |
| 4 | `[Effect@名前]` | 任意 | オフスクリーン描画ごとの割り当て。必要な数だけ続く |

各セクションの後には空行が 1 行入ります。次は全体の例です。

```
[Info]
Version = 3

[Object]
Acs1 = C:\MMD\Accessory\floor.x
Pmd2 = C:\MMD\Model\miku.pmx

[Effect]
Default = none
Acs1 = none
Pmd2 = C:\MMD\Effect\main.fx
Pmd2.show = true
Pmd2[3] = C:\MMD\Effect\hair.fx

[Effect@MirrorRT]
Owner = Acs1
Acs1.show = false
Pmd2 = C:\MMD\Effect\mirror_object.fx

```

## 4. [Info]

| キー | 値 |
| --- | --- |
| `Version` | 整数。現在の MME は 3 を書き、1 から 3 を読む |

## 5. [Object]

### 5.1 行の形

| キー | 値 |
| --- | --- |
| `Pmd<番号>` | モデルファイルのパス |
| `Acs<番号>` | アクセサリファイルのパス |

番号は 1 から始まり、モデルとアクセサリで一つの通し番号を共有します。決まり方は [ファイル同士の関係](07-relations.md) の 2 章にあります。キーに `[n]` や `.show` は付きません。

### 5.2 パスの書き方

MME はパスを次のように書きます。エフェクトファイルのパス（7 章）も同じです。

| ファイルの置き場所 | 書き方 | 例 |
| --- | --- | --- |
| パスの途中に `UserFile` というフォルダがある | `UserFile` から後ろだけの相対パス | `UserFile\Model\miku.pmx` |
| それ以外 | 絶対パス | `D:\stage\stage.pmx` |

相対パスの基準は `UserFile` で始まるかどうかに関わらず、MMD の実行ファイルのあるフォルダです。EMM ファイルのあるフォルダは探されません（検証記録）。

### 5.3 オブジェクト名

ほかのセクションでは `Pmd2` や `Acs1` というキーそのものを、そのモデルやアクセサリの名前として使います。以下ではこれをオブジェクト名と呼びます。

## 6. [Effect]

メイン画面の割り当てです。

| 行 | 内容 |
| --- | --- |
| `Default = 値` | 最初の行。エフェクトファイルのパス、または `none` |
| 割り当ての行 | 7 章の形。オブジェクトごとに並ぶ |

## 7. 割り当ての行

### 7.1 キーの形

| キー | 対象 | 値 |
| --- | --- | --- |
| `<オブジェクト名>` | オブジェクト全体 | エフェクトファイルのパス、または `none` |
| `<オブジェクト名>.show` | オブジェクト全体の表示 | `true` または `false` |
| `<オブジェクト名>[n]` | n 番目の材質（0 から） | エフェクトファイルのパス、または `none` |
| `<オブジェクト名>[n].show` | n 番目の材質の表示 | `true` または `false` |

- `none` は「エフェクトを割り当てない」を表します。
- `.show` の値は小文字の `true` か `false` だけです。
- オブジェクト名は `[Object]` にあるものだけが使えます。
- エフェクトファイルのパスの書き方は 5.2 と同じです。拡張子は fx、fxsub、fxm などです。

### 7.2 並び方

オブジェクトの番号順に、次の順で書きます。値のない行は書きません。

1. `<オブジェクト名>`
2. `<オブジェクト名>.show`
3. `<オブジェクト名>[n]` と `<オブジェクト名>[n].show`（n の小さい順。同じ n では材質のパスが先）

## 8. [Effect@名前]

### 8.1 役割

オフスクリーン描画を使うエフェクトを割り当てると、MME の割り当て画面にタブが増えます。`[Effect@名前]` はそのタブ 1 つぶんの割り当てです。

### 8.2 名前

| 部分 | 内容 |
| --- | --- |
| 名前 | エフェクトファイルが定めたオフスクリーン描画の名前（英数字と `_`） |
| 末尾の `(n)` | 同じ名前のタブが複数あるとき、2 つ目から `(1)`、`(2)` と付く |

例: `[Effect@PointLightRT]`、`[Effect@PointLightRT(1)]`

### 8.3 行

| 行 | 内容 |
| --- | --- |
| `Owner = 値` | 最初の行。このタブを作ったエフェクトの持ち主 |
| 割り当ての行 | 7 章の形 |

`Default` 行はありません。

`Owner` の値は次のどれかです。

| 形 | 意味 |
| --- | --- |
| `<オブジェクト名>` | そのオブジェクトに割り当てたエフェクトが作ったタブ |
| `<オブジェクト名>[n]` | そのオブジェクトの n 番目の材質に割り当てたエフェクトが作ったタブ |
| `<オブジェクト名>@<名前>` | 別のタブ `[Effect@名前]` の中の割り当てが作ったタブ |
| `<オブジェクト名>[n]@<名前>` | 上の 2 つの組み合わせ |

`<名前>` の後ろには `(数字)` が付くことがあります。

`Owner` 行は持ち主を示すだけで、割り当てそのものは行いません。

## 9. 読み込みの検査

MME は次のどれかに当たると、その EMM を読み込みません。

- `[Info]`、`[Object]`、`[Effect]` のどれかがない
- `Version` がない、または 1 から 3 の範囲にない
- `[Effect]` に `Default` 行がない
- `[Effect@名前]` に `Owner` 行がない
- `Owner` や割り当ての行のオブジェクト名が `[Object]` にない

## 付録 A. EMD ファイルとの違い

EMD はモデルやアクセサリ 1 個ぶんの割り当てを保存する形式です。そのファイルと同じフォルダに同じ名前で置くと、読み込んだときに自動で使われます。

| 項目 | EMM | EMD |
| --- | --- | --- |
| 対象 | シーン全体 | モデルまたはアクセサリ 1 個 |
| セクション | `[Info]`、`[Object]`、`[Effect]`、`[Effect@名前]` | `[Info]`、`[Effect]` だけ |
| `Default` 行 | `[Effect]` に必須 | 書けない |
| オブジェクト名 | `Pmd<番号>`、`Acs<番号>` | `Obj` だけ |

EMD の `Obj` 行のパスも相対パスの基準は MMD の実行ファイルのあるフォルダです。

`[Effect]` の `Obj` と `Obj[n]` の値はエフェクトのパスです（7 章の形式）。
