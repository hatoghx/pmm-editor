# 質問と手順の対応

## 1. 概要

質問や依頼から、使う節を引くための表です。節番号の略称（「作業 3.1」など）は [目次](01-index.md) の 3 章のとおりです。

## 2. どの依頼でも守ること

1. 原本の PMM と EMM は書き換えず、別の名前で書き出す（作業 2.1）。
2. 文字コードを決めてから読む（作業 2.2）。
3. 同じ名前の EMM があれば、PMM と一緒に読み、一緒に書き出す（関係 2.1）。
4. モデル名やボーン名が依頼の言葉と完全に一致しないときは、候補を示して確かめる。モデル名には後ろに版や衣装の名前が付いていることが多い。
5. 書き出した後に読み直して、最後の byte まで読めることを確かめる（作業 2.1）。
6. 何を変えたかをモデル名、ボーン名、件数で伝える。
7. 消す、上書きするといった元に戻せない操作は実行する前に利用者に確かめる（移行 7 章）。
