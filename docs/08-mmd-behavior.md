## 2. パスの探し方

### 2.1 用語

| 用語 | 意味 |
| --- | --- |
| 実行フォルダ | MikuMikuDance.exe のあるフォルダ |
| プロジェクトフォルダ | 開いた PMM のパスに `UserFile` が含まれるとき、その手前までのフォルダ。含まれないときはなし |
| カレントフォルダ | Windows がプロセスごとに持つ「今いるフォルダ」。相対パスはここを基準に開かれる |

例えば PMM が `D:\work\UserFile\scene\a.pmm` なら、プロジェクトフォルダは `D:\work\` です。

### 2.2 手順

MMD は PMM の中のパス（モデル、アクセサリ、音声、背景）を次の順に試します。最初に開けたものを使います。

1. パスに `UserFile` が含まれるとき
   1. 実行フォルダ + パスの `UserFile` から後ろ
   2. プロジェクトフォルダ + パスの `UserFile` から後ろ
2. パスをそのまま開く。相対パスはカレントフォルダが基準になる
3. 拡張子が pmd、wav、x、vac のとき、実行フォルダの `UserFile\Model`、`UserFile\Wave`、`UserFile\Accessory` にある同じ名前のファイル

### 2.3 手順から分かること

- `UserFile` を含むパスでは、絶対パスであってもまず実行フォルダの `UserFile` の下が探されます。古い MMD フォルダのパスが残っていても、今の MMD に同じ素材があればそちらが使われます。
- `UserFile` を含まない相対パスが見つかるかどうかは、カレントフォルダしだいです。MMD はモデルを読み込むたびにカレントフォルダをそのモデルのフォルダへ移すため、2 体目以降のモデルの相対パスは見つからないことがあります。
- pmx の拡張子は 2.2 の手順 3 の対象ではありません。
- 他人に渡す PMM のパスを絶対パスか `UserFile` を含むパスにそろえると、開く人の環境に左右されにくくなります。

### 2.4 共有トゥーン

PMX の共有トゥーン（[PMX の参照部分](06-pmx-reference.md) の 5 章）と、PMD のトゥーンの番号 0 から 9 には、MMD の実行フォルダの `Data` にある `toon01.bmp` から `toon10.bmp` が使われます。これは 2.2 の手順の外にあるので、モデルのフォルダにこれらのファイルがなくても読み込めますが、`Data` のファイルを替えると、そのトゥーンを使う材質の陰影が変わります。

`toon01.bmp` から `toon06.bmp` は陰影の付く画像で、`toon07.bmp` から `toon10.bmp` は全面が白の画像（陰影が付かない）です。10 個とも読み込まれます。

## 3. PMM の開き方 3 種の違い

### 3.1 比較

| 項目 | exe のアイコンにドロップ | メニューの「開く」 | ウィンドウへドロップ |
| --- | --- | --- | --- |
| MMD の起動 | 新しく起動する | 起動済みの MMD で開く | 起動済みの MMD で開く |
| パスの受け取り方 | ANSI の文字列 | Unicode の文字列 | Unicode の文字列 |
| ANSI コードページにない文字を含むパス | 開けない | 開ける | 開ける |
| 保存していない変更の確認 | なし（新しい MMD のため） | あり | あり |
| 開く直前のカレントフォルダ | 実行フォルダ | PMM のフォルダ（ファイル選択の画面がカレントフォルダを移すため） | 直前の操作で決まる（前に読み込んだモデルのフォルダなど） |
| 拡張子の判定 | `.pmm` と `.PMM` を含むか | ファイル選択の画面で pmm に限る | `.pmm`、`.PMM`、`.Pmm` を含むか |
| 一度に開けるファイル | 1 つ | 1 つ | 複数（順に処理する） |

### 3.2 違いの理由

- exe へのドロップでは、Windows がパスを ANSI の文字列で MMD に渡します。ANSI コードページにない文字（日本語の Windows の 932 に対する簡体字中国語の文字など）は `?` に置き換わり、ファイルを開けなくなります。
- メニューとウィンドウへのドロップは、パスを Unicode で受け取ります。
- `UserFile` を含まない相対パスの探し方はカレントフォルダで変わります（2.3）。開き方によってカレントフォルダが違うので、同じ PMM でも開き方によってモデルが見つかったり見つからなかったりします。

### 3.3 勧める方法

- 普段はメニューの「開く」を使います。パスの文字の制限がなく、カレントフォルダが PMM のフォルダになるので、PMM のフォルダを基準にした相対パスも見つかります。
- ウィンドウへのドロップも文字の制限はありません。ただし、カレントフォルダが直前の操作で変わるため、相対パスを含む PMM では結果が安定しません。
- exe へのドロップはパスが ANSI コードページの文字だけで書かれているときに使えます。MMD を開く手間が省けます。

## 4. 読み込みの途中で起きること

### 4.1 モデルが見つからないとき

MMD は確認の画面を出し、利用者に次のどれかを選ばせます。

| 選択 | 動作 |
| --- | --- |
| ファイルを指定する | ファイル選択の画面で別のモデルを選び、読み直す |
| 飛ばす | そのモデルを読み込まず、PMM のデータは読み捨てる |
| 中止する | 読み込みを中止する |

### 4.2 アクセサリが見つからないとき

ファイル選択の画面が出ます。取り消すと、読み込み全体が中止されます。

### 4.3 モデルの構造が違うとき

PMM の一覧と PMX が食い違うときの動作は、[ファイル同士の関係](07-relations.md) の 3.2 にあります。

### 4.4 EMM の読み込み

PMM の読み込みが終わると、MME が同じ名前の EMM を読み込みます（[ファイル同士の関係](07-relations.md) の 2.2）。
