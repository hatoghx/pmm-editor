# 質問と手順の対応

## 1. 概要

利用者の質問や依頼から、どの文書のどの手順を使うかを決めるための表です。本書の手順はすべて、ほかの文書の節を指します。

節番号の略称（「作業 3.1」など）は [目次](00-index.md) の 3 章のとおりです。

## 2. どの依頼でも守ること

1. 原本の PMM と EMM は書き換えず、別の名前で書き出す（作業 2.1）。
2. 文字コードを決めてから読む（作業 2.2）。
3. 同じ名前の EMM があれば、PMM と一緒に読み、一緒に書き出す（関係 2.1）。
4. モデル名やボーン名が利用者の言葉と完全に一致しないときは、候補を示して確かめる。モデル名には「YYB式鏡音リン_10th」のように後ろに語が付いていることが多い。
5. 書き出した後に読み直して、最後のバイトまで読めることを確かめる（作業 2.1）。
6. 何を変えたかを、モデル名、ボーン名、件数で利用者に伝える。

## 3. 依頼の例と手順

### 3.1 「YYB式鏡音リンってモデルを元のモデルのすぐ下に複製して」

| 項目 | 内容 |
| --- | --- |
| 確かめること | 対象のモデル（名前の候補が複数あるとき） |
| 手順 | 作業 3.1 |
| EMM | 番号の振り直しは必ず行う（作業 2.5）。エフェクトも写すかは利用者に確かめる。写すなら作業 3.2 |
| 注意 | モデル数の上限は 255 |

### 3.2 「YYB式初音ミクのセンターの外部親情報を全部消して」

| 項目 | 内容 |
| --- | --- |
| 確かめること | 対象のモデル。センターが外部親を持てるボーンか（PMM 5.1 の項目 13） |
| 手順 | 作業 4.1 |
| EMM | 変更なし |
| 注意 | キーごとの外部親（PMM 5.4）と現在状態（PMM 5.6）の両方を消す |

### 3.3 「中国語の pmm ファイルがある。このモデルのこのボーンのモーションを vmd でちょうだい」

| 項目 | 内容 |
| --- | --- |
| 確かめること | 文字コード（作業 2.2。多くは GBK）、対象のモデルとボーン、VMD を使う環境（日本語の MMD か） |
| 手順 | 作業 5.1 |
| 注意 | 名前を使う環境の文字コードに直す（関係 4.3）。VMD のボーン名は 15 バイトまで（関係 4.2） |

### 3.4 「この pmm 壊れてるんだけど、モーションだけでも抽出できない？」

| 項目 | 内容 |
| --- | --- |
| 確かめること | どう壊れているか（MMD で開けない、開けるが動きがおかしい） |
| 手順 | 作業 6.1 で壊れ方を見分け、6.2 から 6.4 で直すか救い出す。その後、作業 5.1 で VMD に取り出す |
| 注意 | 途中で切れたファイルは、切れた位置より後のモデルを救えないことがある |

### 3.5 「このモデルをエフェクトついたまま複製して」

| 項目 | 内容 |
| --- | --- |
| 確かめること | 対象のモデル。同じ名前の EMM があるか |
| 手順 | 作業 3.1 と 3.2 |
| 注意 | 元のモデルが持ち主のオフスクリーン描画のタブは増えない（作業 3.2） |

### 3.6 「pmm のパッケージ化をやって」

| 項目 | 内容 |
| --- | --- |
| 確かめること | 出力先のフォルダ。MMD の実行フォルダの場所（UserFile の相対パスを探すため） |
| 手順 | 作業 7.1 と 7.2 |
| 注意 | 見つからないファイルは一覧にして伝える。パスが 255 バイトを超えたら中止する |

### 3.7 「ゼロから pmm を作成して。モデルは〇〇で、モーションは〇〇」

| 項目 | 内容 |
| --- | --- |
| 確かめること | モデルの PMX のパス、モーションの VMD のパス、カメラの VMD の有無、出力先 |
| 手順 | 作業 8 章 |
| 注意 | VMD のボーン名が PMX と一致しないキーは入らない（作業 5.3） |

### 3.8 「MMD で PMM を、exe アイコンにドロップ、メニューから開く、ウィンドウへドロップの 3 つの操作で開くと何が違う？どうするのがいい？」

| 項目 | 内容 |
| --- | --- |
| 答え | 動作 3.1 の表で違いを示し、動作 3.3 の勧める方法を伝える |
| 要点 | exe へのドロップは ANSI の文字列なので、使えない文字がある。カレントフォルダが開き方で変わるので、相対パスの見つかり方が変わる |

## 4. よくある質問

| 質問 | 答えのある場所 |
| --- | --- |
| 開くと「モデルが見つからない」と出る | 動作 2 章（パスの探し方）、作業 7.3（移設したとき） |

| PMM が使っているファイルを一覧にして | 作業 7.1 の手順 1 と 7.2 |
| EMM の `Pmd3` はどのモデル？ | 関係 2.3 |
| 描画順を変えたらエフェクトがずれた | 関係 2.8、作業 3.5 |
| モデルはいくつまで入る？ | 作業 2.6 |
| カメラの動きを VMD にしたい | 作業 5.2 |
| 外部親を付けたい、付け替えたい | 作業 4.2 |
| VMD を PMM のモデルに読み込ませたい | 作業 5.3 |
| 物体が飛ぶ、値がおかしい | 作業 6.2 |
| ファイルを小さくしたい | 作業 9.1 |
| 文字化けした PMM を直したい | 作業 2.2、9.3 |
