## 2. 依頼を受けたときの進め方

文書は手順の文書（09 から 13）と、仕様の文書（02 から 08）の 2 層です。手順の文書は、依頼を実行する順序と守ることを定めます。仕様の文書は、手順の中で必要になった節だけを引きます。入口は 13 です。

1. [質問と手順の対応](13-question-guide.md) で、依頼に合う手順を探す。依頼が複数の手順にまたがるときは、すべて挙げる。
2. 手順の文書の該当する節を、主軸として読む。
   - ファイルの中身を変える依頼：[ファイル内操作](09-operations.md)
   - 壊れ具合や安全性を確かめる依頼：[安全性検証](10-validation.md)
   - ファイルの収集とパッケージ化の依頼：[パッケージ化](11-dependencies.md)
   - プロジェクトの移動や、別のパソコンへの移行の依頼：[移行](12-migration.md)
3. 手順の中で参照される仕様の節（02 から 08）を、必要になったときに読む。例えば、パスを書き換えるときは、PMM 2.2 と EMM 5.2 を読む。
4. 依頼が MMD での見え方や開き方に関わるときは、[MMD の動作](08-mmd-behavior.md) を読む。
5. 13 の 2 章の決まりを、すべての手順に当てる。
