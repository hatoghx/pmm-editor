# 目次

MMD のプロジェクトファイル（PMM）と、MME の割り当てファイル（EMM）についての資料です。ファイルの形式、ファイル同士の関係、MikuMikuDance の動作、作業の手順をまとめています。

| 番号 | 文書 | 内容 | 読む場面 |
| --- | --- | --- | --- |
| 02 | [基礎知識](02-basics.md) | 用語、ファイルの種類、文字コード | 最初に読む |
| 03 | [PMM ファイル形式](03-pmm-format.md) | PMM の byte 構造 | PMM を読み書きするとき |
| 04 | [EMM ファイル形式](04-emm-format.md) | EMM のテキスト構造 | EMM を読み書きするとき |

## 2. 依頼を受けたときの進め方

1. [質問と手順の対応](13-question-guide.md) で、依頼に合う手順を探す。
2. 手順が指す [ファイル内操作](09-operations.md) の節を読む。
3. 手順の中で参照される形式の節（03 から 06）を読む。
4. 依頼が MMD での見え方や開き方に関わるときは、[MMD の動作](08-mmd-behavior.md) を読む。
5. 依頼が PMM の壊れ具合や安全性を確かめることなら、[安全性検証](10-validation.md) を読む。
6. 依頼がファイルの収集、パッケージ化、素材の整理なら、[パッケージ化](11-dependencies.md) を読む。
7. 依頼がプロジェクトの移動や、別のパソコンへの移行なら、[移行](12-migration.md) を読む。

各文書はほかの文書の節を次の略称で指します。

| 略称 | 文書 |
