# 目次

MMD のプロジェクトファイル（PMM）と、MME の割り当てファイル（EMM）についての資料です。ファイルの形式、ファイル同士の関係、MikuMikuDance の動作、作業の手順をまとめています。

## 1. 文書の一覧

| 番号 | 文書 | 内容 | 読む場面 |
| --- | --- | --- | --- |
| 02 | [基礎知識](02-basics.md) | 用語、ファイルの種類、文字コード | 最初に読む |
| 03 | [PMM ファイル形式](03-pmm-format.md) | PMM のバイト構造 | PMM を読み書きするとき |
| 04 | [EMM ファイル形式](04-emm-format.md) | EMM のテキスト構造 | EMM を読み書きするとき |
| 05 | [VMD ファイル形式](05-vmd-format.md) | モーションファイルの構造 | モーションを取り出す、取り込むとき |
| 06 | [PMX の参照部分](06-pmx-reference.md) | PMM の一覧を PMX から作る方法 | モデルを PMM に入れるとき |
| 07 | [ファイル同士の関係](07-relations.md) | PMM と EMM、PMX、VMD の対応 | 複数のファイルをまたぐ作業のとき |

| 10 | [安全性検証](10-validation.md) | 構造、上限、パス、値の検査 | PMM が壊れていないか、安全に開けるかを確かめるとき |
| 11 | [質問と手順の対応](11-question-guide.md) | 依頼の例から手順を選ぶ表 | 依頼を受けたとき |

## 2. 依頼を受けたときの進め方

1. [質問と手順の対応](11-question-guide.md) で、依頼に合う手順を探す。
2. 手順が指す [作業の手順](09-operations.md) の節を読む。
3. 手順の中で参照される形式の節（03 から 06）を読む。
4. 依頼が MMD での見え方や開き方に関わるときは、[MMD の動作](08-mmd-behavior.md) を読む。
5. 依頼が PMM の壊れ具合や安全性を確かめることなら、[安全性検証](10-validation.md) を読む。

## 3. 節番号の書き方

各文書はほかの文書の節を次の略称で指します。

| 略称 | 文書 |
| --- | --- |
| 基礎 | 02 基礎知識 |
| PMM | 03 PMM ファイル形式 |
| EMM | 04 EMM ファイル形式 |
| VMD | 05 VMD ファイル形式 |
| PMX | 06 PMX の参照部分 |
| 関係 | 07 ファイル同士の関係 |
| 動作 | 08 MMD の動作 |
| 作業 | 09 作業の手順 |
| 検査 | 10 安全性検証 |

例えば「PMM 5.2」は PMM ファイル形式の 5.2 節です。
