# PMM ファイル形式

## 1. 概要

PMM は MikuMikuDance のプロジェクトファイルです。モデル、カメラ、照明、アクセサリ、キーフレーム、画面の状態を一つのバイナリにまとめます。本書はバージョン 0002 の形式を扱います。

言葉の意味は [基礎知識](01-basics.md) にあります。PMX との対応は [PMX の参照部分](05-pmx-reference.md) と [ファイル同士の関係](06-relations.md)、MMD が PMM を開くときの動作は [MMD の動作](07-mmd-behavior.md) にあります。

意味を確かめきれていない項目は、表の中で「未確定」と書きます。理由は [検証記録](10-verification.md) の 5 章にあります。

## 2. 表記と共通の構造

### 2.1 型

| 表記 | 別名 | 内容 |
| --- | --- | --- |
| u8 | byte、uint8 | 符号なし 1 バイト整数 |
| i32 | int、int32 | 符号付き 4 バイト整数（リトルエンディアン） |
| f32 | float、single | IEEE 754 単精度浮動小数（リトルエンディアン） |
| vec3 | Vector3 | f32 を 3 個（x, y, z） |
| quat | Quaternion、Vector4 | f32 を 4 個（x, y, z, w） |
| bool | | u8。0 が偽、1 が真 |
| str8 | VString（可変長文字列） | 長さ（u8）と、その長さのバイト列 |
| fix(N) | CString（固定長文字列） | N バイト固定の文字列。最初の NUL までが値で、残りは不定 |

### 2.2 文字列

- 文字コードは保存した環境の ANSI コードページです。日本語の Windows では CP932（Shift_JIS）になります。
- fix(N) の NUL より後には、以前に使った文字列の残りが入ることがあります。読み込みでは最初の NUL で切り、書き出しでは NUL 以降を 0 で埋めます。
- パスは絶対パスか、相対パスです。相対パスの探し方は [MMD の動作](07-mmd-behavior.md) の 2 章にあります。
- ボーン名とモーフ名は、PMX の名前を ANSI コードページに直し、19 バイトで切ったものです。2 バイト文字の途中で切れることもあります。コードページで表せない文字は失われます。

### 2.3 キーフレーム列

キーフレームはどの列も次の順に並びます。

1. 初期レコード（要素の数だけ。ID は持たない）
2. 追加レコードの件数（i32）
3. 追加レコード（「ID（i32）とレコード」を件数ぶん）

| 列 | 初期レコードの数 | 初期レコードの ID |
| --- | --- | --- |
| ボーン | ボーン数 | ボーンの添字 |
| モーフ | モーフ数 | モーフの添字 |
| 表示・IK・外観 | 1 | 0 |
| カメラ、照明、重力、セルフシャドウ | 1 | 0 |
| アクセサリ（1 個ごと） | 1 | 0 |

各レコードの先頭 12 バイトは共通です。

| 項目 | 型 | 内容 |
| --- | --- | --- |
| frame | i32 | フレーム番号。初期レコードは 0 |
| previous | i32 | 同じ要素の一つ前のレコードの ID |
| next | i32 | 同じ要素の一つ後のレコードの ID。最後は 0 |

連鎖の決まりは次のとおりです。

- 初期レコードから next をたどると、その要素のキーがフレームの昇順に並びます。
- 最初の追加レコードの previous は、初期レコードの ID です。
- 追加レコードの ID はファイルの中で昇順に並び、初期レコードの数以上の値をとります。欠番があってもかまいません。
- 初期レコードの previous は通常 0 です。0 以外の値の意味は未確定なので、読み書きでは元の値を保ちます。

### 2.4 補間曲線

補間曲線は 1 本が 4 バイト（x1, y1, x2, y2）で、値は 0 から 127 です。曲線ごとに 4 バイトがまとまって並びます。

| 対象 | 曲線の順序 | 大きさ |
| --- | --- | --- |
| ボーン | X 移動、Y 移動、Z 移動、回転 | 16 バイト |
| カメラ | X 移動、Y 移動、Z 移動、回転、距離、視野角 | 24 バイト |

### 5.8 モデル ID と表示枠の数

モデル ID は PMM の中でモデルを指す番号です。次の場所から参照されます。

- ヘッダの選択モデル
- 外部親（5.4 と 5.6）
- カメラの親（6.2）と、カメラの追従先（12 章）
- アクセサリの親（8.3 と 8.4）
- 拡張部（13 章）

MMD が保存したファイルでは、ID が 0 から順に並ぶとは限りません。書き出すときは 0 からの連番に振り直してかまいません。その場合は、上の参照もすべて同じ対応で書き換えます。

表示枠の数は多くのモデルで、PMX の表示枠の数に 1 を足した値です。PMX の表示枠と同じ数のモデルもあります。MMD は、この数が読み込んだモデルと合わないとき、表示枠の開閉の値を使わずに読み進めます。そのため、この数が合わなくても読み込みは失敗しません。

| 項目 | 0002 からの違い |
