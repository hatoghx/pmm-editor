# 基础知识

## 1. 作用

本文档汇总处理 PMM 与 EMM 所需的前提知识。其他文档使用此处定义的术语。

## 2. 软件与工具

| 名称 | 说明 |
| --- | --- |
| MikuMikuDance（MMD） | 用于让 3D 人偶动起来并制作视频的 Windows 免费软件。本资料以 9.32 版为基准 |
| MikuMikuEffect（MME） | 嵌入 MMD 使用的扩展软件。通过着色器改变绘制的外观 |

## 3. 文件类型

| 扩展名 | 名称 | 内容 | 创建者 |
| --- | --- | --- | --- |
| pmm | 工程文件 | 整个场景（使用的模型与配件、全部动作、相机、照明、画面设置） | MMD |
| emm | 效果分配文件 | 哪个效果分配给了哪个物体 | MME |
| emd | 单模型分配文件 | 单个物体的效果分配 | MME |
| pmx | 模型 | 人偶的形状、骨架、表情 | 模型作者 |
| pmd | 旧格式模型 | 与 pmx 作用相同 | 模型作者 |
| x | 配件 | 不会动的小物件或背景（DirectX 格式） | 作者 |
| vmd | 动作 | 仅取出动作的数据。有模型用和相机用两种 | MMD |
| fx、fxsub | 效果 | MME 使用的着色器程序 | 作者 |

PMM 不包含模型或配件文件，只记录文件的路径。因此将 PMM 移到别处时，引用可能会失效。

## 4. 场景相关

| 术语 | 含义 |
| --- | --- |
| 模型 | 从 pmx 或 pmd 文件读入的人偶或舞台。具有骨骼和表情 |
| 配件 | 从 x 等文件读入的物体。没有骨骼，只能让位置、旋转、缩放、透明度动起来 |
| 骨骼 | 模型的骨头。具有父子关系，通过移动和旋转使形状运动 |
| 表情 | 改变模型形状的部件，如睁眼闭眼、口型等。用 0 到 1 的权重（weight）决定作用强度 |
| 材质 | 模型表面绘制方式的集合。MME 可以按材质分配效果。EMM 中也称为“子集（subset）” |
| 显示框 | MMD 画面中用于归类显示骨骼和表情的标题 |
| IK | 指定脚尖等位置后，自动计算膝盖和大腿角度的机制。可按关键帧切换启用与禁用 |
| 外部亲（MMD 的界面中写作“外亲”） | 让某个骨骼跟随其他模型的骨骼（或地面）的机制。用于手持小物件等 |
| 付与 | 将某个骨骼的旋转或移动分给其他骨骼的机制（PMX 的功能） |
| 物理计算 | 让头发和裙子在重力下摆动的计算。可按骨骼、按关键帧关闭 |

## 5. 帧

| 术语 | 含义 |
| --- | --- |
| 帧 | 时间单位。MMD 以每秒 30 帧处理 |
| 关键帧（关键） | 某一时刻的值的记录。关键帧之间由插值求得 |
| 插值曲线 | 关键帧之间的变化方式。由贝塞尔曲线的 2 个控制点（4 个数）表示 |
| 初始关键帧 | PMM 为每个要素必定保存的、位于第 0 帧的关键帧 |

## 6. 顺序

| 术语 | 含义 |
| --- | --- |
| 绘制顺序 | 将物体绘制到画面上的顺序。模型和配件各自拥有 |
| 后绘制起始位置 | 配件绘制顺序的分界。在此之前的配件先于模型绘制，其余在模型之后绘制 |
| 计算顺序 | 计算模型动作的顺序。通过外部亲跟随其他模型的模型，必须在对方之后计算 |

## 7. 路径与字符编码

| 术语 | 含义 |
| --- | --- |
| UserFile | 位于 MMD 可执行文件所在文件夹中、用于存放素材的标准文件夹 |
| 绝对路径 | 如 `C:\` 这样从驱动器开始书写的路径 |
| 相对路径 | 以某个文件夹为基准的路径。MMD 与 MME 对基准的确定方式有各自的规则（[MMD 的行为](08-mmd-behavior.md)） |
| ANSI 代码页 | 由 Windows 的语言设置决定的字符编码。用编号表示（见下表） |

MMD 与 MME 用保存文件的环境的 ANSI 代码页书写文件中的字符串。文件中没有字符编码的记录，因此由读取方判断。凡是 Windows 用作 ANSI 代码页的编码都适用。主要的如下。

| 编号 | 语言、地区 | 每个字符的 byte 数 |
| --- | --- | --- |
| 874 | 泰语 | 1 |
| 932 | 日语（Shift_JIS） | 1 或 2 |
| 936 | 简体中文（GBK） | 1 或 2 |
| 949 | 韩语 | 1 或 2 |
| 950 | 繁体中文（Big5） | 1 或 2 |
| 1250 | 中欧 | 1 |
| 1251 | 西里尔文 | 1 |
| 1252 | 西欧（英语等） | 1 |
| 1253 | 希腊语 | 1 |
| 1254 | 土耳其语 | 1 |
| 1255 | 希伯来语 | 1 |
| 1256 | 阿拉伯语 | 1 |
| 1257 | 波罗的语 | 1 |
| 1258 | 越南语 | 1 |

在 1 byte 的代码页中，任何 byte 都对应某个字符，因此读错也不会出现乱码。在使用 2 byte 的代码页（932、936、949、950）中，将名称截为 19 byte 时，可能会在 2 byte 字符的中间被截断。
