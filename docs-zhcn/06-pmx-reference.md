# PMX 的参照部分

## 1. 概要

PMM 从 PMX 文件复制并保存模型的骨骼名、表情名、IK 的列表、可拥有外部亲的骨骼的列表。本文档只记录生成这些列表所需的 PMX 部分，不涉及 PMX 格式的全部。

## 2. 从 PMX 读取的项目

| PMX 的项目 | 使用的信息 |
| --- | --- |
| 模型名、模型名（英文） | PMM 中的模型名 |
| 骨骼 | 名称与标志（第 3 章） |
| 表情 | 名称 |
| 显示框 | 数量 |

PMX 的字符串是 UTF-16 或 UTF-8（由头部决定）。复制到 PMM 时，转换为 ANSI 代码页。

## 3. 骨骼标志

PMX 的每个骨骼有 2 byte 的标志。生成 PMM 的列表时使用以下位。

| 位 | 值 | 含义 |
| --- | --- | --- |
| 2 | 0x0004 | 可移动 |
| 3 | 0x0008 | 显示 |
| 4 | 0x0010 | 可操作 |
| 5 | 0x0020 | IK |

## 4. PMM 列表的生成

| PMM 的项目（PMM 5.1） | 由 PMX 生成的方法 |
| --- | --- |
| 骨骼名（项目 7） | PMX 的全部骨骼，按文件顺序 |
| 表情名（项目 9） | PMX 的全部表情，按文件顺序 |
| IK 骨骼的索引（项目 11） | 具有 IK 位（0x0020）的骨骼的索引，升序 |
| 可拥有外部亲的骨骼的索引（项目 13） | 开头为 −1，其后是符合下列任一条件的骨骼的索引，升序 |
| 显示框的数量（项目 5 与 18） | PMX 的显示框数量加 1（PMM 5.8） |

符合下列任一条件的骨骼可拥有外部亲。

1. 具有 IK 位（0x0020）。
2. 同时具有可移动（0x0004）、显示（0x0008）、可操作（0x0010）这 3 个位。

名称转换为 ANSI 代码页后截为 19 byte（PMM 2.2）。
