# PMX 的参照部分

## 1. 概要

PMM 从 PMX 文件复制并保存模型的骨骼名、表情名、IK 的列表、可拥有外部亲的骨骼的列表。本文档只记录生成这些列表所需的 PMX 部分，不涉及 PMX 格式的全部。另外，为了打包，第 5 章还记录了读取材质所引用的纹理的部分。

## 2. 从 PMX 读取的项目

| PMX 的项目 | 使用的信息 |
| --- | --- |
| 模型名、模型名（英文） | PMM 中的模型名 |
| 骨骼 | 名称与标志（第 3 章） |
| 表情 | 名称 |
| 显示框 | 数量 |

PMX 的字符串是 UTF-16 或 UTF-8（由头部决定）。复制到 PMM 时，转换为 ANSI 代码页。

## 3. 骨骼标志

PMX 的每个骨骼有 2 byte 的标志。生成 PMM 的列表时使用以下位。

| 位 | 值 | 含义 |
| --- | --- | --- |
| 2 | 0x0004 | 可移动 |
| 3 | 0x0008 | 显示 |
| 4 | 0x0010 | 可操作 |
| 5 | 0x0020 | IK |

## 4. PMM 列表的生成

| PMM 的项目（PMM 5.1） | 由 PMX 生成的方法 |
| --- | --- |
| 骨骼名（项目 7） | PMX 的全部骨骼，按文件顺序 |
| 表情名（项目 9） | PMX 的全部表情，按文件顺序 |
| IK 骨骼的索引（项目 11） | 具有 IK 位（0x0020）的骨骼的索引，升序 |
| 可拥有外部亲的骨骼的索引（项目 13） | 开头为 −1，其后是符合下列任一条件的骨骼的索引，升序 |
| 显示框的数量（项目 5 与 18） | PMX 的显示框数量加 1（PMM 5.8） |

符合下列任一条件的骨骼可拥有外部亲。

1. 具有 IK 位（0x0020）。
2. 同时具有可移动（0x0004）、显示（0x0008）、可操作（0x0010）这 3 个位。

名称转换为 ANSI 代码页后截为 19 byte（PMM 2.2）。

## 5. 材质所引用文件的读取方法

PMX 有 2.0 与 2.1 版，此处用到的部分排列相同。从头开始按下列顺序读取。

| 顺序 | 项目 | 内容 |
| --- | --- | --- |
| 1 | 识别 | `PMX `（4 byte）、版本（f32） |
| 2 | 共通设置 | 个数（u8，通常为 8）及该个数的 u8。从头依次为：字符编码（0 为 UTF-16 小端，1 为 UTF-8）、追加 UV 的数量、顶点索引的大小、纹理索引的大小、材质索引的大小、骨骼索引的大小、表情索引的大小、刚体索引的大小 |
| 3 | 模型信息 | 4 个字符串（模型名、英文名、注释、英文注释） |
| 4 | 顶点 | 数量（i32）及每个顶点的记录。记录的大小见下文 |
| 5 | 面 | 索引的数量（i32）及顶点索引的大小 × 数量 |
| 6 | 纹理表 | 数量（i32）及字符串 × 数量。路径以 pmx 所在的文件夹为基准 |
| 7 | 材质 | 数量（i32）及每个材质的记录（下表） |

字符串由长度（i32）及该长度的 byte 构成。

每个顶点记录的大小，是下列各项之和。

- 位置、法线、UV：12 + 12 + 8 byte
- 追加 UV：16 byte × 追加 UV 的数量
- 权重的方式（u8）及各方式的内容（设骨骼索引的大小为 n）
  - 0：n
  - 1：2n + 4
  - 2：4n + 16
  - 3：2n + 4 + 36
  - 4：4n + 16
- 边缘的倍率：4 byte

每个材质记录中，读取引用所需的部分如下。

| 顺序 | 项目 | 类型 |
| --- | --- | --- |
| 1 | 材质名、英文名 | 字符串 × 2 |
| 2 | 漫反射色、镜面色、镜面强度、环境色 | 16 + 12 + 4 + 12 byte |
| 3 | 绘制标志 | u8 |
| 4 | 描边颜色、描边粗细 | 16 + 4 byte |
| 5 | 纹理索引 | 纹理索引的大小（有符号。−1 为未指定） |
| 6 | 球面贴图索引 | 同上 |
| 7 | 球面贴图模式 | u8 |
| 8 | 共享卡通标志 | u8 |
| 9 | 卡通索引 | 标志为 0 时是纹理索引的大小，标志为 1 时是 u8 |
| 10 | 备忘 | 字符串 |
| 11 | 面的数量 | i32 |

共享卡通标志为 1 时，卡通索引 0 至 9 指向 MMD 提供的 `toon01.bmp` 至 `toon10.bmp`。它们位于 MMD 执行文件夹的 `Data` 中。不作为收集的对象。
