# 目录

本资料介绍 MMD 的工程文件（PMM）与 MME 的分配文件（EMM）。内容包括文件格式、文件之间的关系、MMD 的行为以及操作步骤。

## 1. 文档一览

| 编号 | 文档 | 内容 | 阅读时机 |
| --- | --- | --- | --- |
| 02 | [基础知识](02-basics.md) | 术语、文件类型、字符编码 | 最先阅读 |
| 03 | [PMM 文件格式](03-pmm-format.md) | PMM 的二进制结构 | 读写 PMM 时 |
| 04 | [EMM 文件格式](04-emm-format.md) | EMM 的文本结构 | 读写 EMM 时 |
| 05 | [VMD 文件格式](05-vmd-format.md) | 动作文件的结构 | 提取或导入动作时 |
| 06 | [PMX 的参照部分](06-pmx-reference.md) | 由 PMX 生成 PMM 各列表的方法 | 将模型加入 PMM 时 |
| 07 | [文件之间的关系](07-relations.md) | PMM 与 EMM、PMX、VMD 的对应 | 操作涉及多个文件时 |

## 2. 处理请求的方法

1. 在[问题与步骤的对应](13-question-guide.md)中找到与请求相符的步骤。
2. 阅读该步骤所指向的[文件内操作](09-operations.md)中的小节。
3. 阅读步骤中引用的格式小节（03 至 06）。
4. 请求涉及 MMD 中的显示效果或打开方式时，阅读 [MMD 的行为](08-mmd-behavior.md)。
5. 请求是确认 PMM 的损坏程度或安全性时，阅读[安全性检验](10-validation.md)。
6. 请求是收集文件、打包或整理素材时，阅读[打包](11-dependencies.md)。
7. 请求是移动工程或迁移到其他电脑时，阅读[迁移](12-migration.md)。
