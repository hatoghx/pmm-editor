## 2. 路径的查找方式

### 2.1 术语

| 术语 | 含义 |
| --- | --- |
| 执行文件夹 | MikuMikuDance.exe 所在的文件夹 |
| 工程文件夹 | 所打开 PMM 的路径中含有 `UserFile` 时，其前面的文件夹。不含时为无 |
| 当前文件夹 | Windows 为每个进程保存的“当前所在的文件夹”。相对路径以此为基准打开 |

例如 PMM 为 `D:\work\UserFile\scene\a.pmm` 时，工程文件夹是 `D:\work\`。

### 2.2 步骤

MMD 对 PMM 中的路径（模型、配件、音频、背景），按下列顺序尝试，使用最先能打开的。

1. 路径中含有 `UserFile` 时
   1. 执行文件夹 + 路径中 `UserFile` 以后的部分
   2. 工程文件夹 + 路径中 `UserFile` 以后的部分
2. 按原样打开路径。相对路径以当前文件夹为基准
3. 扩展名为 pmd、wav、x、vac 时，执行文件夹的 `UserFile\Model`、`UserFile\Wave`、`UserFile\Accessory` 中的同名文件

### 2.3 由步骤可知

- 对于含有 `UserFile` 的路径，即使是绝对路径，也首先在执行文件夹的 `UserFile` 之下查找。即使残留着旧 MMD 文件夹的路径，只要现在的 MMD 中有相同的素材，就会使用那一个。
- 不含 `UserFile` 的相对路径能否找到，取决于当前文件夹。MMD 每次读取模型都会将当前文件夹移到该模型的文件夹，因此第 2 个以后的模型的相对路径可能找不到。
- pmx 扩展名不属于 2.2 步骤 3 的对象。
- 将交给他人的 PMM 的路径统一为绝对路径或含有 `UserFile` 的路径，可以减少对打开者环境的依赖。

### 2.4 共享卡通

PMX 的共享卡通（[PMX 的参照部分](06-pmx-reference.md)的第 5 章）以及 PMD 的卡通编号 0 至 9，使用 MMD 执行文件夹的 `Data` 中的 `toon01.bmp` 至 `toon10.bmp`。这不在 2.2 的步骤之内，即使模型文件夹中没有这些文件也能读取。替换 `Data` 中的文件，会改变使用该卡通的材质的阴影。

`toon01.bmp` 至 `toon06.bmp` 是会产生阴影的图像，`toon07.bmp` 至 `toon10.bmp` 是整体为白色的图像（不产生阴影）。10 个文件都会被读取。

## 3. PMM 的 3 种打开方式的区别

### 3.1 比较

| 项目 | 拖放到 exe 图标 | 菜单的“打开” | 拖放到窗口 |
| --- | --- | --- | --- |
| MMD 的启动 | 新启动 | 在已启动的 MMD 中打开 | 在已启动的 MMD 中打开 |
| 接收路径的方式 | ANSI 字符串 | Unicode 字符串 | Unicode 字符串 |
| 含有 ANSI 代码页中没有的字符的路径 | 无法打开 | 可以打开 | 可以打开 |
| 未保存更改的确认 | 无（因为是新的 MMD） | 有 | 有 |
| 打开前一刻的当前文件夹 | 执行文件夹 | PMM 的文件夹（因为文件选择画面会移动当前文件夹） | 由之前的操作决定（之前读取的模型的文件夹等） |
| 扩展名的判定 | 是否包含 `.pmm` 与 `.PMM` | 在文件选择画面中限定为 pmm | 是否包含 `.pmm`、`.PMM`、`.Pmm` |
| 一次能打开的文件 | 1 个 | 1 个 | 多个（依次处理） |

### 3.2 区别的原因

- 拖放到 exe 时，Windows 以 ANSI 字符串将路径交给 MMD。ANSI 代码页中没有的字符（例如日语 Windows 的 932 中没有的简体中文字符）会被替换为 `?`，导致文件无法打开。
- 菜单与拖放到窗口，以 Unicode 接收路径。
- 不含 `UserFile` 的相对路径的查找方式，因当前文件夹而异（2.3）。由于打开方式不同，当前文件夹也不同，因此同一个 PMM，有时能找到模型，有时找不到，取决于打开方式。

### 3.3 推荐的方法

- 平时使用菜单的“打开”。路径的字符没有限制，当前文件夹成为 PMM 的文件夹，因此以 PMM 的文件夹为基准的相对路径也能找到。
- 拖放到窗口同样没有字符限制。但是当前文件夹会因之前的操作而改变，因此含有相对路径的 PMM，结果不稳定。
- 拖放到 exe，适用于路径只由 ANSI 代码页的字符书写的情况。可以省去先打开 MMD 的步骤。

## 4. 读取过程中发生的情况

### 4.1 找不到模型时

MMD 会显示确认画面，让用户选择以下之一。

| 选择 | 动作 |
| --- | --- |
| 指定文件 | 在文件选择画面中选择其他模型，重新读取 |
| 跳过 | 不读取该模型，PMM 中的数据被读取后丢弃 |
| 中止 | 中止读取 |

### 4.2 找不到配件时

会显示文件选择画面。取消则整个读取被中止。

### 4.3 模型的结构不同时

PMM 的列表与 PMX 不一致时的动作，见[文件之间的关系](07-relations.md)的 3.2。

### 4.4 EMM 的读取

PMM 的读取结束后，MME 读取同名的 EMM（[文件之间的关系](07-relations.md)的 2.2）。
