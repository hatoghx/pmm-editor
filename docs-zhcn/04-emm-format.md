# EMM 文件格式

## 1. 概要

EMM 是 MME 保存效果分配的文本文件，记录了哪个效果文件分配给了哪个模型或配件。

术语的含义见[基础知识](02-basics.md)。与 PMM 的对应和编号规则见[文件之间的关系](07-relations.md)，依据见[验证记录](../test/verification-en.md)。

## 2. 基本语法

### 2.1 字符与换行

| 项目 | 规则 |
| --- | --- |
| 字符编码 | 保存文件的环境的 ANSI 代码页（基础 7 章的表） |
| BOM | 不加。存在 UTF-8 的 BOM 时，MME 会中止读取 |
| 换行 | CR LF |
| 行的长度 | 最多 1,023 byte |

### 2.2 行的种类

| 种类 | 形式 | 含义 |
| --- | --- | --- |
| 标题 | `[名称]` | 一个区段的开始 |
| 值 | `键 = 值` | `=` 两侧的空格可有可无 |
| 空行 | | 区段之间的分隔 |
| 注释 | 从 `;` 或 `#` 到行尾 | 读取时忽略 |

| 情形 | MME 的处理 |
| --- | --- |
| 行首与行尾的空格 | 忽略 |
| 同一区段中出现两次相同的键 | 使用第一行 |
| 值为空的行 | 拒绝读取 |

## 3. 整体排列

| 顺序 | 区段 | 必需 | 含义 |
| --- | --- | --- | --- |
| 1 | `[Info]` | 是 | 格式的版本 |
| 2 | `[Object]` | 是 | 可以分配效果的模型和配件 |
| 3 | `[Effect]` | 是 | 主画面的分配 |
| 4 | `[Effect@名称]` | 否 | 各离屏渲染目标的分配。根据需要有任意多个 |

每个区段之后各有 1 个空行。完整示例如下。

```
[Info]
Version = 3

[Object]
Acs1 = C:\MMD\Accessory\floor.x
Pmd2 = C:\MMD\Model\miku.pmx

[Effect]
Default = none
Acs1 = none
Pmd2 = C:\MMD\Effect\main.fx
Pmd2.show = true
Pmd2[3] = C:\MMD\Effect\hair.fx

[Effect@MirrorRT]
Owner = Acs1
Acs1.show = false
Pmd2 = C:\MMD\Effect\mirror_object.fx

```

## 4. [Info]

| 键 | 值 |
| --- | --- |
| `Version` | 整数。当前的 MME 写出 3，读取 1 到 3 |

## 5. [Object]

### 5.1 行的形式

| 键 | 值 |
| --- | --- |
| `Pmd<编号>` | 模型文件的路径 |
| `Acs<编号>` | 配件文件的路径 |

编号从 1 开始，模型与配件共用一个编号序列。编号的分配方式见[文件之间的关系](07-relations.md)的第 2 章。该区段的键不带 `[n]` 或 `.show`。

### 5.2 路径的书写方式

MME 按下列方式书写路径。效果文件的路径（第 7 章）也遵循同样的规则。

| 文件的位置 | 书写形式 | 示例 |
| --- | --- | --- |
| 路径中包含名为 `UserFile` 的文件夹 | 从 `UserFile` 开始的相对路径 | `UserFile\Model\miku.pmx` |
| 其他 | 绝对路径 | `D:\stage\stage.pmx` |

以 `UserFile` 开头的相对路径，以 MMD 可执行文件所在的文件夹为基准。其他相对路径，从 EMM 文件所在的文件夹开始解析。

### 5.3 物体名

其他区段把 `Pmd2`、`Acs1` 这样的键本身，用作模型或配件的名称。本文档称之为物体名。

## 6. [Effect]

主画面的分配。

| 行 | 含义 |
| --- | --- |
| `Default = 值` | 第一行。效果文件的路径或 `none` |
| 分配行 | 第 7 章的形式，每个物体一组 |

## 7. 分配行

### 7.1 键的形式

| 键 | 对象 | 值 |
| --- | --- | --- |
| `<物体名>` | 整个物体 | 效果文件的路径或 `none` |
| `<物体名>.show` | 整个物体的显示 | `true` 或 `false` |
| `<物体名>[n]` | 第 n 个材质（从 0 开始） | 效果文件的路径或 `none` |
| `<物体名>[n].show` | 第 n 个材质的显示 | `true` 或 `false` |

- `none` 表示“未分配效果”。
- `.show` 只接受小写的 `true` 或 `false`。
- 只能使用在 `[Object]` 中列出的物体名。
- 效果文件的路径遵循 5.2。扩展名有 fx、fxsub、fxm 等。

### 7.2 顺序

按编号顺序书写各物体，每个物体按以下顺序书写。没有值的行省略。

1. `<物体名>`
2. `<物体名>.show`
3. `<物体名>[n]` 与 `<物体名>[n].show`（n 升序。同一个 n 时，材质的路径在前）

## 8. [Effect@名称]

### 8.1 用途

分配使用离屏渲染的效果后，MME 的分配画面上会增加一个标签页。`[Effect@名称]` 保存这样一个标签页的分配。

### 8.2 名称

| 部分 | 含义 |
| --- | --- |
| 名称 | 效果文件所定义的离屏渲染目标的名称（字母、数字、`_`） |
| 末尾的 `(n)` | 多个标签页同名时，第 2 个带 `(1)`，第 3 个带 `(2)`，依此类推 |

示例：`[Effect@PointLightRT]`、`[Effect@PointLightRT(1)]`

### 8.3 行

| 行 | 含义 |
| --- | --- |
| `Owner = 值` | 第一行。创建此标签页的效果的所有者 |
| 分配行 | 第 7 章的形式 |

没有 `Default` 行。

`Owner` 的值为以下形式之一。

| 形式 | 含义 |
| --- | --- |
| `<物体名>` | 由分配给该物体的效果创建的标签页 |
| `<物体名>[n]` | 由分配给该物体第 n 个材质的效果创建的标签页 |
| `<物体名>@<名称>` | 由另一个标签页 `[Effect@名称]` 中的分配创建的标签页 |
| `<物体名>[n]@<名称>` | 上面两种形式的组合 |

`<名称>` 之后可能带有 `(数字)`。

`Owner` 行只表示所有者，本身不进行分配。

## 9. 读取时的检查

只要符合下列任意一项，MME 就不读取该 EMM。

- 缺少 `[Info]`、`[Object]` 或 `[Effect]`
- 没有 `Version`，或不在 1 到 3 之内
- `[Effect]` 中没有 `Default` 行
- 某个 `[Effect@名称]` 中没有 `Owner` 行
- `Owner` 行或分配行中的物体名不在 `[Object]` 中

## 附录 A. 与 EMD 的区别

EMD 保存单个模型或配件的分配。将同名的 EMD 放在该文件所在的文件夹中，读取时会自动应用。

| 项目 | EMM | EMD |
| --- | --- | --- |
| 范围 | 整个场景 | 一个模型或配件 |
| 区段 | `[Info]`、`[Object]`、`[Effect]`、`[Effect@名称]` | 仅 `[Info]` 与 `[Effect]` |
| `Default` 行 | `[Effect]` 中必需 | 不可有 |
| 物体名 | `Pmd<编号>`、`Acs<编号>` | 仅 `Obj` |
