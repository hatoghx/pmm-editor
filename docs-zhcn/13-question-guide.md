# 问题与步骤的对应

## 1. 概要

这是根据问题或请求，查找所用小节的表。小节编号的简称（如“步骤 3.1”）见[目录](01-index.md)的第 3 章。

## 2. 任何请求都要遵守的事项

1. 不改写原来的 PMM 与 EMM，用其他名称写出（步骤 2.1）。
2. 先确定字符编码再读取（步骤 2.2）。
3. 如果有同名的 EMM，与 PMM 一起读取，一起写出（关系 2.1）。
4. 模型名或骨骼名与请求中的措辞不完全一致时，给出候选项并确认。模型名后面常常带有版本或服装的名称。
5. 写出之后重新读取，确认能读到最后一个 byte（步骤 2.1）。
6. 用模型名、骨骼名、数量告知更改了什么。
